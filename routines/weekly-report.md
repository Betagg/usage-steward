# weekly-report

- Schedule: `0 9 * * 1` (local timezone)
- Name: weekly-report

Check the last 7 days of usage by bot and routine, plus this week's limit.

Send a short report: biggest saving first, then a ranked list of heavy bots and routines, each with a verdict and a concrete fix.

Use real tool data only. Never estimate a missing figure.

Stay quiet if nothing is worth changing.
